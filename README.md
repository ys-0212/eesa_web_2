# Sentry `/welcome` landing-page recreation

A study recreation of <https://sentry.io/welcome/> (landing page only) built with **Next.js 16 (App Router) +
React 19 + TypeScript + Tailwind CSS v4**, using the same animation runtime as the original
(**Rive `@rive-app/canvas` 2.38.5**) plus hand-written CSS/JS ports of its motion.

> **Assets & usage.** The images, illustrations, logos, fonts, Rive file and copy in `public/media/`,
> `src/svgs.ts`, `src/snippets.ts` and `src/content.ts` belong to Functional Software, Inc. (Sentry) and the
> respective customer brands. They are stored here **for private, local study of layout and motion only**.
> Do not deploy, publish or redistribute this project with them — replace them first (see below). The page
> is marked `noindex`, sends no analytics and submits no forms.

Research, specification and comparison reports live in [`analysis/`](analysis):
[`SPEC.md`](analysis/SPEC.md) (tokens, sections, assets, animation + interaction catalogue) and
[`COMPARISON.md`](analysis/COMPARISON.md) (measured differences and check results).

## Requirements

- Node.js 24 (tested with 24.14.0) and npm 11
- Playwright browsers already installed in the shared cache (`%LOCALAPPDATA%\ms-playwright`). This project
  pins `playwright` / `@playwright/test` to **1.64.1** so it reuses the existing Chromium 156 build — do not
  run `npx playwright install` unless you change that version.

## Setup and run

```bash
npm install                 # set PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 to be explicit about not downloading
npm run dev                 # http://localhost:3300 (development)
npm run build && npm start  # http://localhost:3400 (production)
```

Ports 3300/3400 are used so they don't collide with the separate `D:\EESA_WEB` project (3100/3200).

## Quality checks

## Replacing content and media

1. **Copy, links, alt text** — edit `src/content.ts`. Every section reads from it; rich-text fields named
   `html` / `…Html` accept trusted inline markup (`<a>`, `<em>`, `<strong>`).
2. **Images** — drop new files into `public/media/images/` and update the matching path in `src/content.ts`
   (e.g. `tabbedSections[0].tabs[1].image`). Keep the aspect ratios to preserve layout: feature cards 3:1
   (800×267), tab images 3:2 (1200×800), testimonial logos square, hero poster 1366×540.
3. **Hero animation** — replace `public/media/rive/home-hero-scanner-animation.riv` and the poster
   `public/media/images/hero-animation-poster.webp`; set `hero.animation.stateMachine` / `width` / `height` in
   `src/content.ts` to your file's state machine and artboard size.
4. **Fonts** — replace the files in `public/media/fonts/` and the `@font-face` blocks / `--font-*` tokens at
   the top of `app/globals.css`.
5. **Logos & badges (SVG)** — `src/svgs.ts` is generated by `node scripts/media/svg-extract.mjs`. To use your
   own artwork, edit `src/svgs.ts` directly (or stop regenerating it): named entries feed the header, footer,
   badges and icons; `customerLogoSvgs` feeds the logo river (names referenced in `logoRiver.logos`).
6. **Code snippets** — edit `src/snippets.ts` (each line is a list of `[text, colour?]` tokens).
7. **Colours / spacing tokens** — the `@theme` block in `app/globals.css`.

The newsletter form never sends data; wire `components/sections/Newsletter.tsx` to your own endpoint if needed.

## Research & comparison tooling

| Command | Purpose |
|---|---|
| `npm run cdp:host` | Launch the cached Chromium with the dedicated profile `.rea-browser/` and CDP on `127.0.0.1:9222` for the REA MCP tools |
| `node scripts/recon/structure.mjs <url> <w> <h>` | Section tree, computed styles, assets, fonts, keyframes |
| `node scripts/recon/content.mjs`, `sections-html.mjs`, `menus.mjs`, `mobile-menu-tree.mjs`, `snippets.mjs`, `backgrounds.mjs`, `panel-styles.mjs`, `header-geometry.mjs`, `rive.mjs` | Focused reconnaissance (outputs in `analysis/measurements`, `analysis/raw`) |
| `node scripts/media/download.mjs` | Download original media + write `analysis/assets-manifest.json` |
| `npm run capture:reference` / `npm run capture:local` | Full-page + per-viewport screenshots at 1440/1024/768/390 |
| `npm run diff` | pixelmatch diffs → `analysis/diffs/` |
| `node scripts/compare/geometry.mjs` | Heading/probe geometry deltas, reference vs local |
| `node scripts/recon/interactions.mjs <url> <reference|local>` | Interaction screenshots + desktop/mobile videos |
| `node scripts/compare/interaction-diff.mjs` | Diffs the interaction screenshots |
| `node scripts/compare/rive-check.mjs` | Confirms the Rive canvas is live (and the reduced-motion poster fallback) |

Large research outputs (`analysis/screenshots`, `analysis/diffs`, `analysis/videos`, `analysis/raw`) are
git-ignored; regenerate them with the commands above.
